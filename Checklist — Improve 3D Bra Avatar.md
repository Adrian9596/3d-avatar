# Checklist — Improve 3D Bra Avatar

## 1. Body & Anatomy
- [ ] Female body proportions look natural and realistic.
- [ ] Breast shape is soft and anatomically believable.
- [ ] Underbust, side breast, underarm and back areas are clearly defined.
- [ ] Avoid mannequin-like or overly muscular body shapes.
- [ ] Keep body symmetry clean but not unnaturally perfect.

## 2. Skin & Texture
- [ ] Replace flat/plastic skin with realistic PBR skin.
- [ ] Add natural **Base Color variation**.
- [ ] Add subtle **Roughness variation** to remove plastic shine.
- [ ] Add light **micro skin / pore Normal map**.
- [ ] Add subtle **Subsurface Scattering (SSS)**.
- [ ] No obvious texture seams, stretching or repeating patterns.
- [ ] Skin still looks clean at normal viewing distance.

## 3. Breast Area Quality
- [ ] Breast volume comes from mesh, not fake shading.
- [ ] Underbust curve is smooth.
- [ ] Cleavage is natural, not overly deep.
- [ ] Breast-side transition into underarm is smooth.
- [ ] Breast shape remains good from front, side and 3/4 views.

## 4. Lighting & Rendering
- [ ] Use soft neutral studio lighting.
- [ ] Skin highlights are soft, not glossy.
- [ ] No harsh shadows hiding breast geometry.
- [ ] Avatar remains visually clear against a white/light background.

## 5. 3D Interaction
- [ ] Avatar rotates freely 360°.
- [ ] Front / Back / Left / Right / 3/4 views work correctly.
- [ ] Zoom in/out is smooth.
- [ ] Pan and rotate controls feel predictable.
- [ ] Camera does not clip through the avatar.

## 6. Performance
- [ ] Avatar loads quickly in browser.
- [ ] Rotation remains smooth.
- [ ] Texture resolution is high enough without making the tool heavy.
- [ ] No major FPS drop during interaction.

## Definition of Done
- [ ] Avatar looks like a **clean realistic digital fitting model**, not a plastic mannequin.
- [ ] Skin has visible depth without looking overly photorealistic.
- [ ] Breast, underbust, underarm and back anatomy are suitable for bra fitting.
- [ ] Avatar looks good from every rotation angle.
- [ ] 360° interaction is smooth.
- [ ] No visible texture defects.
- [ ] UI stays minimal and the avatar remains the main focus.

**Target visual direction:**  
`Realistic anatomy + clean studio skin + subtle texture + smooth 360° interaction`
